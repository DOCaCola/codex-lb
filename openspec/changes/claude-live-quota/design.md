## Decisions
Observe at physical response headers, including failures, before retries or SSE consumption. Use source ID and captured credential generation. Parse finite nonnegative 5h/7d utilization fractions, preserving zero and overshoot above 1.0. Multiply by 100 without guessing alternative scales; reject overflow/nonfinite percentages. Reset epochs are seconds; no predicted reset or inherited reset when absent. Clamp visual geometry only, never stored utilization.

Store header windows with request-start ordering and receive timestamps in AccountState, separately from polling. Latest request-start evidence wins per window (poll wins ties). A later-completing older poll cannot overwrite newer header evidence. Poll failure does not invalidate a newer header observation. Expired evidence is unknown, never fabricated zero. Other model-specific windows retain their own poll freshness.

Use bounded optimistic state mutation against account version and credential generation; settings patches preserve concurrent header fields. Poll results merge only their fields, without overwriting unrelated settings. Persist header state and throttled history in one transaction, at most one header chart sample per account/window/minute. No detached background tasks. Bound best-effort observation to a short timeout; persistence failure logs a safe reason and cannot fail inference. Cancellation propagates and upstream cleanup remains owned. Do not clear refusal cooldowns from success headers or change token billing.

Source/test evidence: OpenCodex 3cc34e118192 physical-response attribution and guarded cache merge; Sub2API 9a62841fd124 passive sampling. OpenCodex PRs 3809/3825 reject values above 1.0 as a defensive assumption. Sub2API commit e681431454ab53a4d4fa0b8c6930497a14e5bdd0 tests overshoot; Dario issue 1244 reports a physical 5h header of 1.04. CLIProxyAPI issues 5915/5920 report 1.02 for a model-specific window, not global exhaustion. These third-party reports justify retaining overshoot, not guessing its upstream cause or widening rejection scope. No independent live capture was performed.
