## Decisions
Use a reversible envelope for all root compositions rather than implement a partial general-purpose schema-flattening algebra. This is a deliberate refinement of the investigated approach: nested composition has direct third-party acceptance evidence, but our envelope roundtrip needs local qualification and later live Anthropic testing. Missing root type is normalized to object because translated function arguments already require JSON objects. Ordinary explicit object schemas and nested schemas pass through. No reference code is copied (Sub2API is LGPL3; the others MIT).

The internal tool identity records whether arguments are enveloped; stable wire names still derive only from caller name/namespace/kind. Streamed wrapped JSON is bounded and buffered until block completion. One unwrapped delta precedes done; malformed envelopes never publish executable arguments. Non-stream output uses the same codec. History uses current declaration encoding: changed or removed declarations reproject original logical arguments, not stored upstream wrapper JSON. Names, namespace, call IDs, tool choice, and result pairing are unchanged.

Schema walking is bounded, visits schema positions rather than user property names or literal defaults, and rewrites local JSON-pointer refs when relocating under properties.arguments. External refs, identifiers/anchors/dynamic scopes, unknown dialect-dependent scope controls and invalid compositions are explicit named errors rather than silent guesses. JSON-pointer targets are checked without expanding recursive refs. Native Messages remains unchanged because its preservation contract and wire format require a separate native codec design.
