# Design

Claude's database capability remains `supports_responses=true` and `supports_chat_completions=false`: those fields describe upstream wire capability. Chat source lookup additionally admits Claude with Responses support. The Chat endpoint maps requests to Responses, and invokes the existing source dispatch with a Chat output mode. The source dispatcher remains the sole owner of admission, reservation, retry, settlement, and transport cleanup.

Chat-specific output limits and stops are passed as Responses projection controls, then translated to Messages. Unsupported behavioral controls fail before sending. Canonical Chat messages and instructions are retained separately from the exact projected input sent to Claude. For authenticated clients' tool turns, the bounded disk replay store retains source/model/key/conversation metadata. A unique full visible-history and complete call-set match restores only genuine signed blocks when its projected input also matches the sequentially projected prior history. If the match is missing, expired, anonymous, ambiguous, incompatible, or no longer sequentially valid, only the affected caller-visible tool cycle is converted as a unit to ordinary assistant text plus paired, quoted user result data; no native tool-use block or fake signature remains from that cycle. Completed plaintext reasoning also becomes ordinary assistant textual history, unless genuine signed active replay already accounts for it. New tool declarations and reasoning controls remain in force.

The Chat response mapper emits text, tool calls, usage and explicit terminal status. Unknown incomplete reasons produce an error. Streaming mapping runs inside the dispatch settlement body so client disconnect and post-open errors retain ownership. Completed tool output retention is attempted before the downstream completion boundary is yielded; a store failure leaves the next turn on visible reconstruction. An interrupted stream is not represented as a completed tool turn. Both Chat projection generators close their nested upstream generators on direct closure.
